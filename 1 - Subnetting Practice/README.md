# Subnetting Practice

- For this section, I decided to practice subnetting. The goal of this section is to provide a sufficient number of IP addresses for each department and logically divide the network into separate subnets.

- To verify that the calculated subnets work as intended, one PC from each department was used to ping all other PCs within its own subnet, as well as PCs belonging to the other subnets.

- To further demonstrate the concept of subnetting, all PCs were connected to a single switch, with their IP addresses and subnet masks being the only configurations distinguishing the different subnets. No routing was configured at this stage.

- The image documentation is organized using the following numbering convention:

  1. Setup/Topology and Subnetting Solutions
  2. IP Address and Subnet Mask Configuration per PC
  3. Ping Tests WITHIN and BEYOND the Subnets
