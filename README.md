A practical Cisco networking project built in Cisco Packet Tracer to apply and reinforce concepts covered during my CCNA 200-301 preparation.

This project simulates the development of an office network from the perspective of a network engineer, progressively implementing networking concepts as the project evolves.

---

## 💡 Project Background

The idea for this project came from my experience working in an office environment where employees primarily used laptops and connected to the available network to access the internet.

This made me think:

> **"What if I were the network engineer responsible for designing and maintaining this company's network?"**

I decided to turn that question into a practical project.

Rather than completing isolated Packet Tracer exercises, I wanted to build a single network that could progressively evolve as I reviewed and applied the concepts covered by the CCNA 200-301 curriculum.

The result is this simulated office network.

---

## 🎯 Purpose

This project serves two purposes:

1. **CCNA Preparation**  
   To reinforce networking concepts through hands-on implementation while preparing for the Cisco CCNA 200-301 certification.

2. **Practical Portfolio Project**  
   To demonstrate the ability to apply networking concepts to a realistic network scenario, document configurations, test connectivity, and troubleshoot problems.

The goal is not simply to configure devices, but to understand **why** a particular network design or technology is being used.

---


The network will be progressively developed as additional requirements and networking concepts are introduced.

---

## 🗺️ Project Approach

Rather than building the final network immediately, the network is developed incrementally.

Each stage builds upon the previous one.
